Test CORS – ČÚZK WFS parcely

Ověřuje, jestli lze volat služby ČÚZK přímo z JavaScriptu v prohlížeči (bez proxy). Klikni postupně na tlačítka.

⚠️ Důležité: otevři tuto stránku přes http:// nebo https:// (např. nahraná na GitHub Pages, nebo spuštěná přes python -m http.server), ne dvojklikem ze souboru (file://) – to by mohlo test CORS zkreslit.

Stejná služba, jakou už používáme v protokolech a generátorech. Slouží jen jako referenční "funguje / nefunguje".

Test 3 — WFS parcely, průnik s linií (GetFeatureByPolygon)

Toto je klíčový test pro náš případ — pošle otevřenou linii (ne uzavřený polygon) a měl by vrátit všechny parcely, které linie protíná. Přesně tenhle princip použijeme pro komunikace.
